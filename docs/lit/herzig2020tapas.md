# herzig2020tapas: TAPAS: Weakly Supervised Table Parsing via Pre-training
Jonathan Herzig, Pawe{\l} Krzysztof Nowak, Thomas M{\"u}ller, Francesco Piccinno, Julian Martin Eisenschlos | ACL 2020 | https://arxiv.org/abs/2004.02349 | verified: yes (page fetched)

- Problem: table QA from question-answer denotations without logical forms.
- Method: BERT-style pretraining on tables; selects cells and applies an aggregation operator, trained weakly supervised.
- Relation: cell-selection TableQA ancestor; TAPAS also appears as a baseline in MultiHiertt (Table 4) and TAT-QA.
- Verification: arXiv abs page (comments: Accepted to ACL 2020; DOI 10.18653/v1/2020.acl-main.398). Numbers not extracted (abstract-level note).
