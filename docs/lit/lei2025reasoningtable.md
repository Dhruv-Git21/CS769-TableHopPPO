# lei2025reasoningtable: Reasoning-Table: Exploring Reinforcement Learning for Table Reasoning
Fangyu Lei, Jinxiang Meng, Yiming Huang, Tinghong Chen, Yun Zhang, Shizhu He, Jun Zhao, Kang Liu | arXiv preprint | https://arxiv.org/abs/2506.01710 | verified: yes (page fetched)

- Problem: RL for table reasoning (also text-to-SQL).
- Method: rule-based outcome rewards, data preprocessing and training strategy (abstract).
- Key numbers (abstract): beats Claude-3.7-Sonnet by 4.0% on table reasoning benchmarks; 68.3% on BIRD dev with a 7B model.
- Relation: trace-level outcome-RL competitor; our dense hop reward is the contrast. Preprint, not peer reviewed per arXiv page.
